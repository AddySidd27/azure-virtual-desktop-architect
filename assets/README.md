# Assets

**Status: currently empty of binary assets by design.**

## What this folder is for

Supporting files that are not Markdown, Mermaid, SVG, or Terraform: any exported images, downloadable checklists, or sample data files a reader might want alongside a chapter or lab.

## Why it is empty today

All diagrams in this book are stored as text-based, version-controlled source (`.mermaid`, `.svg`, `.drawio`) directly under [`../diagrams/`](../diagrams/), not as flat image exports here, so that diagrams remain editable and diffable rather than opaque binaries. No chapter or lab currently requires a downloadable asset beyond its own Terraform and diagram sources.
