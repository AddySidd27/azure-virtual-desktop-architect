# Bicep

**Status: comparison notes only. Not a parallel Bicep implementation of every Terraform module.**

## What this contains

Terraform is the primary infrastructure-as-code tool throughout this book, and every lab's working implementation is in Terraform under [`../terraform/`](../terraform/). Where a chapter discusses infrastructure as code, it includes a short Bicep-versus-Terraform comparison for that specific decision (state management, module structure, provider ecosystem, when Bicep is the better default for an Azure-only estate) rather than a duplicate Bicep build of the same lab.

## What is planned here

Bicep equivalents for the published lab modules (2-4 today, more as later labs are published), kept in sync with the Terraform versions, for readers who want to compare the two directly rather than read about the difference. This is a lower priority than completing the Terraform lab sequence itself, since Terraform is the book's primary path.
