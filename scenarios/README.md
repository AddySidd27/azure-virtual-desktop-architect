# Architecture Case Studies

Fifteen fictional case studies are included. Each follows the [project standard](../PROJECT-STANDARD.md).

These are learning and portfolio exercises, not customer delivery records. Read the requirements, design a solution, and then compare it with the documented approach. Numbers and results are assumptions, worked examples, or validation targets unless separate lab evidence is linked.

Structure and build order: [Structure change 02](../appendices/structure-change-02-projects.md), revised by [Structure change 03](../appendices/structure-change-03-project-led.md)

Concepts not covered in Chapters 1 to 25 are introduced inside the project where an engineer would need them. See the [concept coverage map](../appendices/concept-coverage-map.md).
